## Sobre

Atuo na interseção entre QA e sistemas de IA/LLM, garantindo qualidade em produtos de IA para contact centers.

- Testes funcionais e exploratórios de agentes conversacionais e pipelines de IA
- Escrita de cenários de teste (BDD / Gherkin)
- Validação de regras de negócio e conformidade com PRDs/Figma
- Auditoria de acurácia de classificadores e avaliação de respostas de LLM
- Report de bugs claro e objetivo, com rastreabilidade
- Documentação técnica e de processos de QA

---

## Ferramentas e stack de QA

- **Automação:** Playwright, testes E2E
- **CI/CD:** Jenkins
- **Observabilidade:** Grafana, Allure Report
- **IA aplicada a QA:** TestMap MCP (geração assistida de casos de teste), avaliação de qualidade de chamadas com LLM
- **Dados:** SQL, construção de datasets de avaliação (gabaritos)
- **Cloud:** AWS Step Functions
- **Versionamento:** Git
